# Participant information and consent

**Project.** A prototype tool for finding moments in Gaelic football match footage,
built as a portfolio project for a PhD application at TU Dublin.

**What you will do.** In a screen-shared session of about fifteen minutes, you will
use a web interface to find specific clips from a single match, talking through what
you are doing as you go. There are four short tasks, each with a ninety-second
target, followed by six workload questions and a short conversation.

**What is recorded.** Screen and audio for the session, plus timestamps of the
searches you run and the clips you open. Your name appears only on this form; in all
notes, analysis and write-up you are identified as a code (P1, P2, and so on).

**What happens to it.** Recordings are stored locally, are not uploaded anywhere,
and are deleted once the session notes are written up. Only anonymised, aggregate
results appear in the write-up, which may be shared with a prospective PhD
supervisor and may appear in a public code repository.

**Your choices.** Participation is voluntary and unpaid. You can decline any task,
stop the recording, or end the session at any point without giving a reason and with
no consequence. You can ask for your data to be deleted up until the point it is
aggregated — after that it cannot be separated out. Tell me and it is gone.

**The tasks are not a test of you.** The tool is what is being evaluated. If
something is confusing, that is a result, and a useful one.
